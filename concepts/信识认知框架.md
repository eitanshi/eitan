## 定义

以汉字「信·识·认·知」四字为骨架，将人类认知的发生过程建模为「信息基底 → 识别 → 确认 → 内化」循环的**隐喻模型**。

> ⚠ 本框架为启发式隐喻，非字源学严格论证，亦非认识论完整理论。

## 核心结构

```
        识（识别 / 启一）
        /        \
       /          \
      v            v
  信（基底） → 认（确认 / 行动）
     \            /
      \          /
       v        v
        知（内化 / 抽象）
```

### 四字详解

| 字 | 释义 | 认知阶段 |
|:--|:-----|:---------|
| **信** | 人言归一、自心唯一、确定 | 基底 — 信息之「源」，确定性的支点 |
| **识** | 识别、起始、信号中辨别人 | 启动区分 — 从混沌中划出第一刀 |
| **认** | 与人言、合二、行动 | 确认/承诺 — 将识别付诸行动 |
| **知** | 归心、抽象、值、结果 | 内化 — 形成稳定表征 |

## 核心论点

### 源头原理

- **信在中心**：不是四字并列，而是信（确定性基底）支撑识/认/知的展开
- **三角循环**：识→认→知，每一步增加一个维度，但永不离开信
- **生成公式**：信（一）→ 识、认（一生二）→ 知（二生三）→ 万物（三生万物）

### 已识别的边界

| 限制 | 说明 |
|:----|:------|
| 简化字拆字不严谨 | 识的繁体是「識」，甲骨文/金文需另外考证 |
| 选字标准缺失 | 为何选这四字而非思、想、念、意，未给出选择标准 |
| 与现代数学的映射仅为隐喻 | 时域/频域/相位对应是借喻，非机制推导 |
| 自我指涉 | 用「信→识→认→知」过程解释信识认知本身 |

## 辩论过程

- **正方**：字形结构类比认知阶段有教学/传播价值；信作为基底、识认知作为环节在结构上自洽
- **反方**：字源学层面简化字拆字违规；三角方向缺论证；现代概念映射跨越度过大
- **共识**：保留 60% 框架（三角 + 字源隐喻），降级 40%（与现代数学的硬推导标注为隐喻）

## 人 vs 人类 的嵌套解读

本框架进一步衍生出关键区分：

| | 人 | 人类 |
|:--|:---|:-----|
| 数 | 一 | 二、三、万 |
| 时间 | 当下 | 时间 |
| 确定性 | 可以确定 | 必然不确定 |
| 状态 | 静、定、见证 | 动、变、演化 |
| 类比 | 观察者 | 演化流 |
| **对应** | **信（中心）** | **识/认/知（三角）** |
