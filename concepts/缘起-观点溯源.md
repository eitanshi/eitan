## 定义

**缘起**（Dependent Origination）是光启系统 v2 的核心新增能力——追踪每一个观点的起源、演化、分化和结晶的全过程，使得知识不再是孤立卡片，而是有基因的活体网络。

> 命名来自佛教术语「缘起」——万物依因缘而生起。一个观点的出现必定有它的前因（哪次对话触发的）和过程（经过怎样的打磨）。

## 为什么需要缘起

### 三个痛点

| 痛点 | 现象 | 缘起的解法 |
|:----|:-----|:-----------|
| **观点失忆** | 三个月后翻到一张卡片，忘记自己当时为什么会产生这个观点 | `lineage` 字段标记完整的演化链，从萌芽→展开→成型 |
| **重复劳动** | 同样的问题在 Qwen 和 MiniMax 里分别讨论过，各自产生有价值的洞察，但彼此孤立 | 多源 raw/ 统一标记 `source_type`，卡片层面汇聚 |
| **信任崩塌** | 苏格拉底式讨论推翻了一个旧观点，但旧卡片还在，读者不知道已经被修正了 | 新卡片标注 `lineage` 指向旧卡片，或在旧卡片中标记 `contested: true` |

### 一个具体例子

你关于「信识认知框架」的思想演化链：

```
2026-07-04 MiniMax对话
  ├─ 首次提出："信识认知"四字骨架图
  ├─ 推导出：信(中心) = 人(一)，识认(三角) = 人类(万)
  └─ 协同 MiniMax 完成对抗式验证（字源漏洞 + 自我指涉）
         ↓
2026-07-04 wiki 沉淀
  ├─ concepts/信识认知框架 — 核心结构 + 限定
  └─ concepts/认知架构-操作流程 — 五步协议 + AI 众生相
         ↓
未来演化
  └─ v2: 甲骨文/金文字源层
  └─ v3: 实战场景化（决策流程、笔记系统）
  └─ v4: 找反例检验排他性
```

没有缘起系统，三个月后你只能看到两张孤立的卡片，无从还原它们是怎么被生出来的。

## 缘起三要素

任何一个观点的演化都可以用三个要素描述：

### 1. 源头（Source）—— 观点是从哪里来的

| 源头类型 | 示例 | 标记方式 |
|:--------|:-----|:---------|
| Hermes 苏格拉底式对话 | 你提观点 → Hermes 追问 → 达成共识 | `raw/观点-2026-07-04-xxx.md` (source_type: hermes) |
| 外部 AI 对话 | MiniMax Mavis 提取的对话 | `raw/观点-2026-07-04-xxx.md` (source_type: minimaxchat) |
| Qwen 网页对话 | Qwen 中讨论的技术方案 | `raw/` (source_type: qwenchat) |
| 外部材料 | 你读到的一篇文章、一本书 | `raw/` (source_type: external) |

### 2. 过程（Process）—— 观点是如何被打磨的

| 步骤 | 说明 | 谁做的 |
|:----|:-----|:-----|
| 萌芽 | 一个模糊的想法、一个直觉 | 你 |
| 摆相 | 把想法摊开，完整呈现正反两面 | AI（众生相） |
| 剥析 | 苏格拉底式追问，找出漏洞和矛盾 | Hermes |
| 共识 | 双方达成一致的核心结论 | 你 + Hermes |
| 结晶 | 写成 wiki 卡片 | Hermes（你审阅） |
| 重组 | 与已有知识关联，归入 lineage | Hermes |

### 3. 演化（Evolution）—— 观点如何变化

| 演化类型 | 含义 | 标记方式 |
|:--------|:-----|:---------|
| 深化 | 同一个观点被进一步挖深 | 新卡片 lineage 指向旧卡片 |
| 修正 | 旧观点的某部分被推翻 | 新卡片 lineage 指向旧，旧卡片标注 contested |
| 分化 | 一个观点拆成多个子观点 | 子卡片 lineage 指向母卡片 |
| 汇聚 | 多个观点融合为一个 | 新卡片 lineage 列出所有前驱 |
| 否定 | 旧观点被完全推翻 | 旧卡片标注 archived，新卡片 lineage 注明推翻关系 |

## 操作方法

### 写新卡片时

```yaml
---
title: 新观点
lineage: [[concepts/信识认知框架]]   # 这个观点从信识认知框架演化而来
---
```

### 查某个观点的演化历史

1. 打开观点卡片，看「缘起溯源」表格
2. 如果这个观点是前驱，顺着 `[[Wikilink]]` 往后找

### 查询所有观点的演化关系

```bash
# 搜索所有带有 lineage 字段的卡片
grep -r "lineage:" ~/knowledge/wiki/concepts/
```

### 发现新观点与旧观点有关时

1. 在 SCHEMA.md 的「更新策略」下，按规范处理
2. 如果推翻：旧卡片标记 `contested: true`，新卡片 lineage 指向旧
3. 记录到 log.md：`evolved_from → evolved_to`
