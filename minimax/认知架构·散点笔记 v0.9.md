# 认知架构 · 散点笔记 v0.9 · 字源同构：人 / 从 / 众 = 点 / 线 / 面

> 状态：已记录。v0.8 留的"人从众生相"挂起句被字源学坐实。
> 性质：v0.8 的字源学补全，不是新概念。

---

## 一、字源学的三个并行映射

> 人 = 一人。从 = 二人。众 = 三人。
> 点，线，面。

| 数 | 字（人） | 几何 | 周易 | 横向 |
|---|---|---|---|---|
| 1 | **人** | **点** | 太极 | 识 |
| 2 | **从** | **线** | 两仪 | 认 |
| 3 | **众** | **面** | 三才 | 知 |

> **三点确定一面。三人构成一世界。**

---

## 二、杀手锏：众 = 众生相（字源直证）

```
众   = 三人
众生 = 众多的生命
众生相 = 众的相 = 众所显现的世界
```

> 众生相 = 三个或以上的存在所构成的现象世界。
> 这是**字源学的本体论**：现象世界的存在条件是至少三个存在者。

### 对 v0.8 挂起句的字源学解读

> "人从众生相"

字源学：
- **人** = 1 = 点
- **从** = 2 = 线
- **众** = 3 = 面 = **众**生相
- **人从众生相** 字面 = "人从 众 生 出" = "1 从 3 出现"

含义：
- 1 怎么从 3 出现？**点在面上**——点在面上，看起来是 1，其实跟 2 一起定义了 3
- **人不能独立于众生相——人是众生相上的点**

> **人 = 众生相上的点**。这是字源学，不是隐喻。

## 五、没把握的连接

### Q1：道 = 0 还是 1？

两种可能：
- (a) **道 = 0**（在点之前，在 1 之前）—— 道 = 无
- (b) **道 = 0/1 之间**（道的"生一"动作）

> 道德经第 42 章："道生一，一生二，二生三，三生万物"
> - 如果 道 = 0，那"道生一"是 0 → 1（点从无到有）
> - 如果 道 = 1，那"道生一"是 1 → 1（点的自我确认）

**我直觉是 (a)**：道 = 0 = 0 维 = 无维度 = 在点之前。
- 0 维不是"不存在"，是"无延展"——纯在，无关系
- 道 = 0 = 真正的"无"——不是空，是"道之为物，惟恍惟惚"

### Q2：欧拉公式 e^(iπ) + 1 = 0 怎么对应？

- **0** = 道
- **1** = 识（点 / 人）
- **π** = 认（圆 / 从 / 线展开）
- **e** = 自然（生长律）
- **i** = 虚 / 现象 = 阳

> 欧拉公式可能是**所有这些数的同一性表达**——但需要展开专题。

### Q3：4 维（体）和 v0.6 的"算"是否对应？

- 算 = 竹+目+廾 = 看 + 操作 + 工具 = 三维操作
- 算 = 4 维？—— 加上"操作"作为第 4 维（时间？）
- 算数 = 从面进入体 = 4 维 = 3D 操作

> 这一条是猜测，待专题展开。
