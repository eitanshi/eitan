# 认知架构 · 散点笔记 v0.3

> 状态：**接近收敛**。散点快速收拢到道法术器 / 道德经序列。

## 一、4 个 Q&A 汇总

### Q1：15 个态都有意义吗？

- ✅ **都有意义**。不是空集。
- **识 / 认 / 知 = 周易 = 变化**（横向轴本质 = 变化的三相位）
- 梦/觉/醒/悟/道 = 定义的状态（纵向轴）
- **15 个组合都存在**——每一个是"某个变化在某个状态上的样子"
- **因天时 / 地利 / 人和**（因缘不同）→ 同一个组合可能呈现完全不同的相

> 结构 vs 具体：
> - 结构 = 道法术器 + 三轴
> - 此刻 = 因缘合和

### Q2：悟是状态还是动作？

- 这里是**状态**。悟 = 心 + 吾 = 观自在。
- **汉字含义皆有阴阳两种属性**——状态 / 动作可转换
- 例子：
  - 悟（动）= 把主体内化为心
  - 悟（静）= 主体在心中持有
- 这条推及所有汉字：每个字自带状态/动作两个读法

### Q3：道法术器和横向纵向的关系？

- **元框架**（a）—— 描述"认知在哪一层发生"
- 借用道法术器给认知**分层、结构化、数字化**
- 数字化 = 离散化 = 朝 1/0 走

### Q4：道法术器 vs 一生二二生三

**同构**：

```
道生一    →  道
一生二    →  自然
二生三    →  法（法于阴阳）
三生万物  →  术（合于术数：认数 / 识数 / 算数）
器        →  万物（具象化）
```

> **道法术器不是 4 个独立层级，是道德经序列的 4 个稳定相位**。
> 台阶之间是自然展开。
> v0.2 的三轴框架从"借用框架"升级为"**自然结构**"。

## 二、两条主线（重点）

### 主线 1：识/认/知 = 周易 = 变化

| 横向 | 周易 | 性质 |
|---|---|---|
| 识 | 变化之始 | 阴、潜在 |
| 认 | 变化之显 | 阳、显现 |
| 知 | 变化已成 | 阴阳合、凝固的相 |

### 主线 2：道法术器 = 道德经

| 道德经 | 道法术器 | 性质 |
|---|---|---|
| 道 | 道 | 原则、一、序 |
| 一生二 | 自然 | 自然展开 |
| 二生三 | 法 | 阴阳、法则 |
| 三生万物 | 术 | 术数、计数 |
| 万物 | 器 | 具象、万物 |

## 三、汉字阴阳二义（暗线）

> 汉字含义皆有阴阳两种属性，状态动作可能会转换。

| 字 | 动（阳） | 静（阴） |
|---|---|---|
| 悟 | 主体内化为心 | 主体在心中持有 |
| 信 | 言说 | 心持 |
| 观 | 看 | 自在 |
| 道 | 言 | 行 |

> 汉字字源学在架构里的位置：
> **字源不是溯源（v0.1 反对的）**。
> **是如字本身所是地看**——一个字本来就有两面，不去查它"原本"是什么。

## 四、15 个态命名（草图）

```
          梦/睡    觉    醒    悟    道
  识      潜识    启识   明识   洞识    —
  认      暗认    微认   显认   透认    —
  知      隐知    浅知   已知   真知    —
```

- **道列空**——道不在识/认/知中展开（道是横轴的基底）
- 每个态配一个**因缘值**（天时 / 地利 / 人和）
- 任何一个态 = 一个变化 × 一个状态 × 一个因缘
