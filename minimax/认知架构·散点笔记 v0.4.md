# 认知架构 · 散点笔记 v0.4

## 一、智慧 = 智 + 慧

### 1.1 字源拆解

| 字 | 字源 | 性质 |
|---|---|---|
| **智** | 知 + 曰 | "知"说出来——**智是表达出来的知** |
| **慧** | 音 + 回 + 自心 | 声音回到本心——**慧是内化的音** |

- 智 = 表 / 言 / 外向
- 慧 = 里 / 心 / 内向
- 智慧 = 智 + 慧 = 表里合一

### 1.2 对位

| 字 | 对应 |
|---|---|
| 智 ↔ 知 | 智是知的阳面（说出来） |
| 慧 ↔ 心 | 慧是心的回面（回来） |
| 智慧 = 智 + 慧 = 知 + 心 = **知心的能力** |

### 1.3 推论

如果 信字古形从心言（v0.1 假设）：
- 信 = 慧 + 智 + 心 + 言 = 智慧合一的字
- **信 = 智慧的字形化**——这一条待字源学确认（v0.1 原则：不溯源，但如字所见）

## 二、觉 / 醒 对位（v0.3 笛卡尔积的修正）

> 觉合知，醒合识

| 横向 | 纵向对位 | 解读 |
|---|---|---|
| 识 | **醒** | 识的纵向是醒——识别要醒来 |
| 认 | **？**（待定） | 认的纵向对位未明 |
| 知 | **觉** | 知的纵向是觉——知道要觉醒 |

### 关键洞察：大多数人卡在"睡"，不是"醒"

- 修行的瓶颈不是"醒"不够
- 是"觉"不到位
- **觉 = 知的纵向状态 = 知道后能回到本心**
- 大多数人一辈子没到"觉"，更没到"醒"

## 三、为学日益，为道日损

道德经第 48 章：

> 为学日益，为道日损。损之又损，以至于无为。

### 解读

| | 为学 | 为道 |
|---|---|---|
| 方向 | 加 | 减 |
| 动作 | 知道更多 / 识得更全 / 积累 | 损 / 舍 / 退 / 不追求 |
| 结果 | 日益（多） | 日损（少） |
| 终点 | 学问家 | 觉 / 道 |

> **什么时候不在追求更多更强，才是"觉"。**
> 觉 = 减法达到的状态，不是加法堆出来的。

### 对 v1 协议的影响

- AI 的"摆全量" = 为学日益（加）
- 人 的"观 / 不取" = 为道日损（减）
- 5 步流程 = **加（摆）→ 减（观）→ 减（行 / 断言）→ 减（归）**

> **协议的本质是减**——AI 加得越全，人减得越净，觉才出得来。

## 四、信 vs 相信（v0.4 核心新增）

### 4.1 拆分

| | 信 | 相信 |
|---|---|---|
| 性质 | **状态** | **动作** |
| 时序 | 在时序里（当下） | 在时间里（过程） |
| 确定性 | 已是确定 | 在不确定中找确定 |
| 起点 | 自心 | 看到的相 |
| 动作 | 无 | 有 |
| 根 | 自心唯一 | 不确定 |

### 4.2 经典中的"信"

**西方**：「信我得永生，我即自心」
- 基督 = 自心
- 永生 = 不在时间里（v0.2 "道不在时间里"的另一说法）
- 信基督 = 信自心
- 这里的"信"= **信**（状态），不是相信（动作）

**东方**：「信以为真」
- 信 = 把某物当作真的来承担
- 状态读 = 信（自心）= 已是真
- 动作读 = 相信（见相方信）= 把相当真

### 4.3 对 v0.1 原则的加深

v0.1 原则：不溯源 = 因为训诂学家在做"相信"，不在"信"
- 训诂 = 见相方信
- 信 = 直接是自心，不需见相

> **不靠相信，证到信。**——v0.1 原则的本体层根据

## 五、跨传统：上帝 = 自心

> 上帝说：信我得永生，我即自心。

"我即自心"——这是**你加的注**，不是圣经原话。
- 圣经原文：信子（Son）得永生
- 你的翻译：信自心得永生

这是把基督教神学**翻译成自心学**：
- 基督 = 自心
- 永生 = 不在时间里
- 信基督 = 信自心

### 处理方式

- ✅ **记录**（已记入本节）
- ❌ 不进 v2（保持佛 + 道 + 儒的纯粹性，等你定调）
- 🔜 跨传统整合 = 未来专题
